# Java Learning Roadmap

Chương trình học Java được xây dựng nhằm cung cấp kiến thức từ cơ bản đến nâng cao, giúp người học nắm vững ngôn ngữ Java, tư duy lập trình hướng đối tượng, các công nghệ Backend và khả năng xây dựng ứng dụng thực tế.

## Mục tiêu chương trình

- Nắm vững cú pháp và các nguyên lý cơ bản của Java.
- Hiểu và vận dụng lập trình hướng đối tượng (OOP).
- Làm việc với cấu trúc dữ liệu, thuật toán và Collections Framework.
- Thành thạo Java Core và các tính năng quan trọng của Java hiện đại.
- Làm việc với cơ sở dữ liệu thông qua JDBC, JPA và Hibernate.
- Xây dựng RESTful API bằng Spring Boot.
- Nắm vững các kiến thức về bảo mật, kiểm thử và triển khai ứng dụng.
- Có khả năng xây dựng một dự án Backend hoàn chỉnh.

## Cấu trúc chương trình học

Chương trình được chia thành các giai đoạn chính:

### 1. Java Fundamentals

Kiến thức nền tảng về ngôn ngữ Java.

- Tổng quan về Java và JVM, JRE, JDK.
- Cài đặt môi trường phát triển.
- Biến, kiểu dữ liệu và toán tử.
- Câu lệnh điều kiện và vòng lặp.
- Mảng và String.
- Method và cách tổ chức chương trình.
- Exception Handling.

### 2. Object-Oriented Programming (OOP)

Tìm hiểu lập trình hướng đối tượng và cách tổ chức mã nguồn.

- Class và Object.
- Encapsulation (Tính đóng gói).
- Inheritance (Tính kế thừa).
- Polymorphism (Tính đa hình).
- Abstraction (Tính trừu tượng).
- Interface và Abstract Class.
- Composition và Association.

### 3. Java Core & Advanced

Các kiến thức quan trọng trong hệ sinh thái Java.

- Collections Framework.
- Generics.
- Lambda Expressions.
- Stream API.
- Functional Interface.
- Optional.
- Multithreading và Concurrency.
- File I/O và Serialization.
- Java Memory Management và Garbage Collection.

### 4. Database & Persistence

Làm việc với cơ sở dữ liệu và cơ chế lưu trữ dữ liệu.

- SQL cơ bản và nâng cao.
- Database Design.
- JDBC.
- Connection Pooling.
- ORM Concepts.
- JPA và Hibernate.
- Transaction Management.

### 5. Spring Framework & Spring Boot

Phát triển ứng dụng Backend bằng hệ sinh thái Spring.

- Spring Framework Overview.
- Dependency Injection (DI).
- Inversion of Control (IoC).
- Spring MVC.
- Spring Boot.
- RESTful API.
- Spring Data JPA.
- Spring Validation.
- Spring Security.
- JWT Authentication và Authorization.

### 6. Backend Development & System Design

Các kiến thức phục vụ xây dựng hệ thống thực tế.

- Layered Architecture.
- Design Patterns.
- SOLID Principles.
- Redis và Caching.
- Message Queue (RabbitMQ/Kafka).
- Logging và Exception Handling.
- API Documentation với Swagger/OpenAPI.
- Unit Testing và Integration Testing.
- Docker và CI/CD.
- System Design cơ bản.

## Kết quả đầu ra

Sau khi hoàn thành chương trình, người học có thể:

- Phát triển ứng dụng Java theo kiến trúc phân tầng.
- Thiết kế và quản lý cơ sở dữ liệu.
- Xây dựng RESTful API với Spring Boot.
- Triển khai xác thực và phân quyền.
- Tích hợp các hệ thống bên ngoài.
- Kiểm thử, đóng gói và triển khai ứng dụng.
- Phân tích và thiết kế hệ thống Backend ở mức cơ bản.
